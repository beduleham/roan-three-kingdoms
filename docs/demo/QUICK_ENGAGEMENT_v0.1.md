# 아군 전진·교전 시작 v0.1

## 기능

편성만 확인한 뒤 기본 시작을 누르면 부대가 대기하고 있어 전투 진입 방법이 불명확했다. 새 버튼은 플레이어가 명시적으로 아군 전체의 공격 태세·공격 이동을 한 번에 지시하는 로컬 시험 단축 동작이다.

- tick 0, 일시정지, 준비 중인 스킬 없음, 대기 입력 없음, 전술 목적지 지정 모드가 아닐 때만 사용한다.
- 변경한 편성이 아직 적용되지 않았으면 버튼을 잠그고 편성 적용·초기화를 안내한다.
- 현재 살아 있는 아군 전체를 선택하고 SET_STANCE(aggressive), ATTACK_MOVE를 기존 send 경계로 전달한다. 공격 이동 목적지는 시험 편성의 적 초기 위치 중심이다. 이후 재생을 시작한다.
- 실제 상태를 즉시 변경하지 않고 다음 코어 tick에서 명령을 검증한다. 로그에는 기존 두 명령과 로컬 플레이어 ID가 기록되어 재현할 수 있다.
- Q/W/R, 진형 변경, 후퇴, 적군 조작을 자동 실행하지 않는다. AI가 전략을 독단적으로 고르는 기능이 아니다.
- 이미 시작한 경기, 일시정지 중인 진행 경기, 종료 상태에서는 재호출하지 않는다. 초기화·재시험 후 다시 사용할 수 있다.
- 기존 수동 시작/계속과 이동·공격·태세 조작을 유지한다. 이미 준비한 명령을 덮어쓰거나 대기 명령을 버리지 않는다.

## 수정 파일

- `apps/client/src/session.ts`: 사용 가능 조건, 명시적 두 군령 전달·재생 시작.
- `apps/client/src/main.ts`: 버튼·안내, 편성 미적용 검증, 대기/진행/종료 상태별 잠금.
- `apps/client/src/style.css`: 전진 시작 영역.
- `apps/client/test/session.test.ts`: 소유권·재현 로그·중복 호출·기존 대상/대기 입력 유지·전술 모드 검증.
- `apps/client/e2e/demo.spec.mjs`: 빠른 교전으로 정상 전투→전멸 결과→재시험, 미적용 편성/대상 지정/수동 입력 잠금과 스킬 수동 사용 확인.

## 범위

부대 2대2 로컬 시험 진입을 돕는 단축 명령이다. 진행 중의 적 위치에 맞춰 목표를 계속 바꾸거나 전술을 자동 판단하지 않는다. 현재 시야가 공개된 시험 편성의 초기 좌표를 사용하며 정식 전장의 안개·정찰 규칙에 맞춘 기능은 후속 설계다. 전투 수치, 국가 점수·거점 승리, 성장과 보상은 변경하지 않았다. 시험 편성의 종료 시간이나 결과를 검증된 병종 밸런스로 해석하지 않는다.

## 최종 브라우저 결과

최종 소스의 실제 Chromium 브라우저 검사 18개 모두 통과했다. 새 미적용 편성 잠금, 준비 중인 스킬·대기 명령 보존, 스킬 수동 사용, 교전 시작→전멸 결과→실제 다운로드 로그 재생→같은 편성 재시험, 기존 90초 UI/헤드리스 상태·이벤트 해시 일치를 포함한다. 준비 화면도 실제 렌더링으로 확인했다.
