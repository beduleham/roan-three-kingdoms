# 적군 관측·이름표 선택 v0.1

## 적용 기능

일반 상태에서 적 부대 또는 적 이름표를 왼쪽 클릭하면 지휘판에 해당 적의 상태를 표시한다. 아군 선택은 유지되어 정보를 확인한 뒤 기존 아군으로 명령을 이어갈 수 있다. 관측은 입력 큐나 코어 상태를 바꾸지 않으며 적군 조작 권한을 주지 않는다.

- 관측 정보: 병종, 병력, 체력, 사기, 전열, 현재 행동, 태세, 진형.
- 실제 state 값을 사용하며 게임 tick이 진행되면 갱신된다. 일시정지·전투 종료 시에는 멈춘 상태를 보여준다.
- 관측 중인 이름표에 `◇ 관측`을 표시한다. `◆ 선택` 아군 표식과 구분한다.
- 다른 아군을 선택해도 관측 창은 유지한다. 닫기 버튼 또는 전투 초기화·재시험에서 해제한다.
- 분리 배치된 이름표는 자신의 부대 ID에 연결된다. 부대 그림이 겹쳐도 이름표를 통해 정확히 선택/관측할 수 있다. 이름표 왼쪽 클릭을 우선하고 우클릭의 기존 이동/공격 판정은 유지한다.
- Q/W/R 대상 지정 중에는 이름표 클릭도 대상 지정으로 처리한다. 관측 창으로 전환해 준비 중인 군령을 취소하지 않는다. 적군 소유권·명령 유효성은 기존 코어 검증을 유지한다.
- 전멸한 적도 화면 안에 표시된 이름표로 관측할 수 있다.

## 수정 파일

- `apps/client/src/session.ts`: 코어 밖 관측 ID와 관측/해제 검증. 초기화에서 정리.
- `apps/client/src/main.ts`: 적군 관측 창, 실시간 게이지, 클릭 우선순위, 이름표 표시와 읽기 전용 디버그 값.
- `apps/client/src/style.css`: 주홍 계열 관측 구역과 기존 지휘판 배치.
- `apps/client/test/session.test.ts`: 아군 선택·준비 중인 군령·리플레이 불변성, 유효하지 않은 ID와 소유권, 전멸 관측·초기화.
- `apps/client/e2e/demo.spec.mjs`: 부대/이름표 클릭, 아군 선택 유지, 군령 대상 지정 우선, 실제 HP·사기·전열, 화면 크기·카메라 변환, 닫기·초기화.

## 범위와 남은 기획

현재 로컬 데모는 전장의 모든 부대 상태를 가지고 있으며 전장의 안개·첩보·정보 은폐가 없다. 이번에는 관측 UI만 추가했다. 정식 경쟁 모드에서 적군 정보 공개 범위, 시야 밖 관측 유지와 추정치, 상세 상태 공개 여부는 별도 설계 대상이다. 피해량·명중·AI·시야 규칙은 변경하지 않았다. 새 전투 기획 수치는 확정하지 않았다.

## 최종 브라우저 결과

최종 클라이언트 소스의 전체 17개 검사 중 16개 통과(90초 실행·리플레이·전멸 결과 포함). 남은 검사는 적 클릭 시 이전의 소유권 거부 메시지를 기대하던 항목이었다. 새 관측 동작에 맞춰 적 정보 표시·아군 선택 유지·리플레이 불변성을 검사하도록 갱신하고 해당 검사와 새 관측 검사 2개를 재실행해 모두 통과했다. 이 마지막 변경은 테스트 기대값에만 적용했으며 클라이언트 소스는 전체 검사 시점과 동일하다. 따라서 브라우저 17개 시나리오가 각각 통과했으며 최종 테스트 파일 전체를 단일 실행으로 재검사한 것은 아니다.
