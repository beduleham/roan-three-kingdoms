# 부대 이름표 가독성 v0.1

적용 범위는 로컬 Phaser 전투 데모의 부대 이름·병력·상태 문구 배치다.

- 선택 부대를 먼저 배치하고 같은 우선순위에서는 ID 순서로 배치한다. 가까운 이름표가 겹치면 위·아래의 빈 자리에 배치한다.
- 화면 가장자리에서 이름표가 잘리지 않도록 8px 여백을 둔다. 화면 밖 부대의 이름표는 숨긴다. 공간이 부족하면 우선순위가 낮은 이름표를 숨긴다.
- 이름표 하단에서 해당 부대 군기 위치로 안내선을 그린다. 이름표를 이동해도 실제 부대 위치나 클릭 판정은 바뀌지 않는다.
- 텍스트 실제 크기를 사용하므로 패주·붕괴·전멸 문구가 붙어도 배치에 반영된다. 카메라 스크롤은 월드 좌표 기준으로 처리한다.

## 수정 파일

- `apps/client/src/label-layout.ts`: 순수 표시용 배치 정책.
- `apps/client/src/main.ts`: 이름표 패딩·배치·안내선, 읽기 전용 디버그 정보.
- `apps/client/test/label-layout.test.ts`: 밀집·화면 경계·입력 순서·좁은 화면 검증.
- `apps/client/e2e/demo.spec.mjs`: 실제 전투·카메라 이동 중 겹침/화면 경계 검사.

## 검증

- `npm run typecheck`: 통과.
- `npm test`: 221개 통과.
- `npm run build`: 통과. 기존 대형 번들 경고는 남아 있다.
- `npm run format:check`: 통과.
- 실제 Chromium 브라우저: 기존 9개 검사(90초 실행과 리플레이 일치 포함) 통과. 새 이름표 검사는 대기 제한을 수정하고 실제 Q 이후 HP 감소를 기다리도록 강화해 별도 재실행, 통과. 최종 수정은 새 검사에만 적용했으며 클라이언트 소스는 기존 9개 통과 시점과 동일하다.

## 남은 범위

현재 4개 부대 규모의 데모용 정책이다. 다수 부대에서의 공간 부족, 안내선 교차, 장수와 병사 그림의 겹침은 별도 개선 대상이다. 줌·클러스터링·이름표 클릭 선택은 추가하지 않았다. 전투 수치·명령·승패 규칙은 바꾸지 않았다. 기획 확정이 필요한 새 전투 규칙은 없다.
