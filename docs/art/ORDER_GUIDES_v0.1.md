# 선택 부대 교전·명령 안내 v0.1

선택한 부대가 어디로 이동하고 어느 적을 상대하는지 표시한다. 실제 전투 코어가 적용한 상태만 읽고, 대기 중인 UI 입력은 미리 확정 표시하지 않는다.

## 적용 파일

- `apps/client/src/order-view.ts`: 표시용 순수 정책. 교전/추격 대상, 지정 공격, 이동, 공격 이동, 후퇴, 복귀, 돌격을 구분한다.
- `apps/client/src/main.ts`: 선택 부대의 안내선·목적지 마름모·대상 십자/지면 링과 하단 상태 문구. 읽기 전용 디버그에 현재 표시 중인 안내 정보를 제공한다.
- `apps/client/test/order-view.test.ts`: 상태 우선순위, 대상 중복·아군·전멸 필터, 입력 불변성, 완료 상태 검증.
- `apps/client/e2e/demo.spec.mjs`: UI 명령 적용 전후, 선택 변경, Q 이후 실제 대상, 초기화 검증.

## 표시 정책

- 교전·추격과 지정 공격: 주홍색. 현재 대상과 같은 지정 공격은 중복 표시하지 않는다.
- 이동: 청록색. 공격 이동·돌격: 금색. 후퇴·기준 위치 복귀: 파란색.
- 공격 이동 중에는 실제 상대와 최종 목적지를 함께 표시할 수 있다.
- 돌격은 상대의 현재 위치가 아닌 코어에 고정된 돌격 목적지를 사용한다. 복귀 상태는 현재 기준 위치를 사용한다.
- 패주·붕괴·재정비·전멸에서는 이전 이동/공격 안내를 표시하지 않는다. 명령 완료와 초기화 시 사라진다.

## 범위와 한계

직선 점선은 출발 부대와 대상/목적지의 관계를 보여 주는 안내선이며 경로 탐색이나 충돌 예측 결과가 아니다. 전투 수치, 병사 AI, 명령 허용 규칙, 승패 규칙은 변경하지 않았다. 겹친 부대의 원화 자체를 분리하거나 타깃 부대를 밀어내지 않는다. 복수 선택 시 안내선이 교차할 수 있으며 대규모 부대용 묶음 표시는 후속 작업이다. 새로 확정한 전투 기획 수치는 없다.
