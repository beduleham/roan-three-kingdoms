# 편대 표시와 선택 식별 v0.1

## 적용

- `formation-view.ts`: 최대 8명의 표시 병사를 좌우 두 열씩 배치하고 중앙 통로를 비운다. 표시 좌표만 변경하며 개별 병사 AI나 충돌체는 만들지 않는다.
- `main.ts`: 선택한 살아 있는 부대에 청록색 모서리 표식을 병사 그림 위에 그린다. 이름표에도 `◆ 선택` 문구를 추가한다. 단일·Shift 복수 선택을 따른다.
- 살아 있는 장수 표시에는 아군 파랑/적군 빨강 바탕에 청동색 테두리 마름모를 붙인다. 부상으로 숨겨진 장수에는 그리지 않는다.
- 이름표 기준 높이를 90px에서 112px로 올려 장수 마름모와 겹치는 것을 줄였다. 이름표와 표식의 초기 겹침 여부를 브라우저에서 검사한다.
- 병사·장수는 발 위치의 Y좌표로 앞뒤 순서를 유지한다. 실제 장수 위치·명령 판정·전투 수치는 변경하지 않는다.

## 검증 파일

- `apps/client/test/formation-view.test.ts`: 중앙 통로, 8개 슬롯, 좌표 변환 및 원본 불변성.
- `apps/client/e2e/demo.spec.mjs`: 실제 스프라이트 좌표, 장수 표식, 단일/복수 선택 문구 검사.

## 남은 작업

현재 시각화는 실제 병력 수 전체가 아닌 최대 8명의 대표 병사다. 다른 부대와 근접할 때의 그림 겹침, 무기 길이에 따른 겹침, 장수 전용 초상/명패, 병종별 세부 진형은 남아 있다. 이 표시 편대는 기본진·방어진·공격진의 실제 전술 효과를 설명하는 최종 진형 디자인이 아니다. 새로 확정한 전투 기획 수치는 없다.
