## 사용자에게 보이는 변화
- 먹선·광물 안료색의 평지 배경. 길·바위·망루는 장식이며 충돌/지형 효과 없음.
- 선택 부대의 체력·사기·응집도 각각 표시. 복수 선택 시 각 부대 표시.
- 군령패 Q/W/R에 준비 또는 재사용 시간(초) 표시. 장수 비활동/쿨다운 시 버튼 비활성.
- Q 목표 지정→실행→진행→적중/종료를 실제 상태와 사건으로 표시.
- 대상이 준비되지 않았으면 확인 버튼 비활성. 키보드 명령과 실제 실행의 최종 검증은 기존 코어 유지.
- 테스트 편성·전술/진형/도움말·증강·전체 부대·장수 상세·사건 로그를 접을 수 있음.
- 아군 전멸 시 재시작 안내. 테스트 다시 시작은 현재 편성으로 세션 초기화.
- 코어/전투 설정/승리 규칙 변경 없음.

## 남은 항목
- 한 방향 정적 무장·기병·창병. 보병/궁병은 도형. 방향별 애니메이션·모든 병종·진형별 병사 배치 미완료.
- 배경은 한 장의 평면 장식. 무한 스크롤 맵/장애물/고저차/FOW 미구현.
- 병사 배치 및 라벨 겹침, 군기·초상·스킬 아이콘의 세부 미술 확장 필요.
- 배경 SVG 약 4.17MB, JS 약 3.07MB로 초기 원본 용량이 큼. PNG/WebP/atlas 파이프라인 최적화와 캐시 분리가 후속.
- 군령패는 CSS 기반 첫 UI이며 최종 조형/상호작용 디자인 아님. 작은 화면과 복수 선택 시 화면 높이 사용을 추가 검토.
