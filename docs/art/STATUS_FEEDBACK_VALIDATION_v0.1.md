# 로딩 정리와 전투 상태 표시 v0.1
기준일: 2026-10-26

## 로딩 최적화
- 더 이상 표시하지 않는 초기 unit-art.ts와 foot-units.svg의 import/preload 제거. 원본 파일은 기록용으로 유지.
- 초기 unit-strip 텍스처 등록 제거. 장수 리소스 누락 시 원형 표식으로 대체.
- 최신 빌드 JS: 1,384,548 bytes. 직전 단계 3,083,184 bytes 대비 약 55% 감소.
- JS gzip: 약 1.64MB → 0.39MB. 이전 1.55MB foot-units.svg도 배포 산출물과 요청에서 제외.
- 전체 이미지 용량이나 실제 로딩 시간이 55% 감소했다는 의미는 아님. 현재 사용 중인 방향별 SVG 원화 최적화는 후속.
- 이름표 색상은 시각 상태 key가 달라질 때만 setStyle하여 같은 스타일의 반복 텍스처 갱신 방지.

## 상태 표시
- squad-feedback.ts의 순수 함수로 표시 정책 분리.
- 실제 음수 HP delta의 ATTACK_HIT 수신 시 2tick 동안 피격색. 연속 피격이면 색 유지.
- 패주: 기울어진 군기, 붉은 상태 라벨/영역, 낮은 투명도.
- 붕괴: 낮은 투명도와 상태 라벨/영역.
- 전멸: 회색 표식과 전멸 라벨, 살아 있는 군기 숨김.
- ROUTED/BROKEN/REGROUP 또는 hp=0에서는 직전 공격 사건이 남아도 공격 포즈를 사용하지 않음.
- reset 시 피격 캐시도 초기화. 일시정지 시 표시 유지.
- 신규 전용 피격/패주/전멸 원화는 미추가. 기존 원화의 색·투명도·군기·문구를 코어 상태에 연결한 단계.
- 전투 코어, 부대 AI, 스킬 및 수치 변경 없음.
