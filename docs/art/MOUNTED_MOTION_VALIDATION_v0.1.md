# 무장·기병 방향별 이동과 돌격 표시 v0.1
기준일: 2026-10-26

## 적용
- 기병과 백마 무장 각각 4방향 × 4포즈 이동 시트.
- 기병은 코어의 facing, 무장은 실제 이동 벡터를 바라봄. 정지한 무장은 본대 facing을 사용하며 본대가 없으면 기본 방향.
- 실제 위치 변화로 이동 여부를 판단. 무장의 본대 동행과 재배속도 코어 좌표를 표시하며 클라이언트가 위치를 만들지 않음.
- 일반 이동은 tick/2 프레임, 실제 Q 돌격 이동은 tick 프레임. 현재 100ms tick에서 각각 5fps/10fps.
- Q는 별도 전용 공격 시트가 아닌 같은 이동 포즈의 빠른 재생과 먼지 효과로 구분.
- 먼지는 실제 cavalry charge와 위치 변화가 있을 때만 표시. 위치와 tick에서 계산하며 무작위/판정 효과 없음.
- 일시정지하면 이미지와 먼지 위상도 고정. reset 시 이동 캐시 초기화.
- WOUNDED 장수는 숨김, EXPOSED 장수의 재출전 좌표 변화는 달리기로 표시하지 않음.
- 코어/스킬 수치/이동/충돌 규칙 변경 없음.
