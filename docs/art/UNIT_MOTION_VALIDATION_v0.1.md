# 병종 리소스와 창병 동작 v0.1
기준일: 2026-10-26
## 적용 범위
- 창병: 화면 기준 우하/좌하/좌상/우상 4방향. 이동 시트 16포즈, 공격 시트 16포즈.
- 보병: 방패·검, 궁병: 활·화살통 정적 이미지 추가. 현재 생존한 4개 병종 모두 이미지 표시.
- 보병/궁병/기병은 한 방향 원화와 좌우 반전만 지원. 무장·기병의 정식 방향별 동작은 미완료.
- 전투 core/설정 변경 없음. 병사 이미지는 squad 상태에서 파생한 최대 8개 표시이며 개별 AI·충돌·병력 판정을 추가하지 않음.

## 표시 정책과 제작 파이프라인
- unit-motion.ts: core facing을 화면 4방향 행으로 변환. 이동은 실제 위치 변화, 공격은 실제 ATTACK_HIT 사건으로 결정.
- 최근 4tick 안의 ATTACK_HIT가 있으면 공격 시트, 그 외 이동 시 이동 시트, 정지 시 첫 이동 포즈 표시.
- 프레임은 floor(tick/2)%4의 tick 동기 루프. 연속 적중 때 매번 첫 프레임으로 되돌리지 않음. 일시정지 시 프레임도 정지.
- 공격 동작은 실제 적중 사건 뒤의 표현용 루프이며 선딜·후딜·공격 판정 시점의 재설계가 아님. 단발 사건에서 4포즈 전체를 순차 재생하는 one-shot 시스템은 후속.
- reset 시 이동/공격 표시 캐시를 지워 이전 전투 동작이 남지 않도록 함.
- SVG 파일은 PNG 원본을 담는 컨테이너이며 원본 픽셀은 변경하지 않음. 메타데이터로 실제 frame 영역을 지정.
- 생성 시트가 정규 격자 경계를 정확히 지키지 않아 공격 시트를 재제작. 투명한 세로 여백에 맞춘 가변 프레임 폭과 원래 중심점 offset을 사용.
- 각 frame의 alpha >32 부분이 경계에 닿지 않음을 검사. 실제 표시 비율은 frame 폭/높이 유지.
- 발 아래 alpha 경계로 originY 정렬. 이동/공격 사이 배율은 중앙 silhouette 높이를 기준으로 보정. 골격 기준의 수작업 정렬과 동작 연마는 후속.
