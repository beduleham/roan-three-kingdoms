# 그래픽 제작 가이드 v0.1
기준일: 2026-10-26 / 사용자 승인 방향: 채색 병서 속 전장 × 지휘관의 군막
상태: 미술 방향 확정. 아래 픽셀·배율·색상은 첫 적용을 위한 임시 규격이며 플레이 검증 후 조정한다.

## 1. 시각 정체성
- 고정 쿼터뷰 2D 일러스트. 카메라 회전 없음.
- 먹선과 광물 안료색: 청록·황토·주홍·쪽빛. 바탕 종이 질감은 낮은 대비로 제한.
- 군기는 소속과 부대 상태의 핵심 표식. 성씨·국가 문양은 미확정이며 임시로 생성하지 않는다.
- UI는 칠목·죽간·청동·붉은 인장. 일반 설명과 수치는 고딕체, 제목에만 붓글씨.
- 후한 말~삼국시대 복식과 장비에서 출발. 고증 확인 전 역사적 정확성을 주장하지 않는다.
- 인장은 자체 추상 문양으로 제작하고 임의의 한자를 생성하지 않는다.

## 3. 첫 리소스 범위와 잠정 규격
| 리소스 | 원본 셀 | 게임 표시 높이 초안 | 기준점 |
|---|---|---|---|
| 기마 무장 | 256×256 | 약 84px | 말의 지면 접점 중앙 |
| 기병 | 256×256 | 약 64px | 말의 지면 접점 중앙 |
| 창병 | 256×256 | 몸체 약 48px, 창 포함 별도 검수 | 두 발 사이 지면 |
첫 샘플은 남동 방향 대기 포즈 각 1개. 이후 8방향을 목표로 방향별 실루엣을 검증한다.
좌우 반전은 무기·방패·갑주 비대칭을 확인한 경우에만 허용한다.
모든 셀에 무기·군기·그림자 여백을 두고 자동 크롭으로 기준점을 바꾸지 않는다.
원본 셀 해상도와 화면 표시 크기를 구분한다. 수량·표시 높이는 전투 규칙이 아니다.

## 4. 애니메이션과 파일 구조
최초 정적 샘플 검증 후 대기·이동·기본 공격·피격·패주 순서로 확장한다.
프레임 수와 재생 속도는 동작 테스트 후 결정하며 생성 시트의 정렬을 신뢰하지 않는다.
제안 경로:
- apps/client/public/art/v0.1/units/ : 투명 PNG, 이후 atlas PNG+JSON
- apps/client/public/art/v0.1/ui/ : 군령패·인장·초상화
- apps/client/src/presentation/ : 투영·병사 배치·깊이·애니메이션
- docs/art/ : 가이드와 검수 기록
메타데이터에는 key, 파일 경로, 프레임 크기, 기준점, 방향, 표시 배율, 라이선스/생성 이력을 기록한다.
그림자는 별도 렌더링하는 것을 우선 검토한다. AI 원화의 잔여 그림자와 이중 적용 금지.

## 5. 코어와 표시 계층
코어 좌표·명령·판정·정수 tick은 유지한다. 투영은 클라이언트 표시에서만 수행한다.
투영 초안: sx = originX + (x-y)*scaleX, sy = originY + (x+y)*scaleY.
역변환을 클릭·우클릭·목표 지정에도 적용하고 카메라 이동/배율을 먼저 역산한다.
깊이는 투영된 발 위치와 안정적인 ID 순서로 정렬한다.
병사는 squad 상태에서 파생된 장식적 배치이며 개별 병사 AI·충돌·HP를 코어에 추가하지 않는다.
부대별 병사 표시 수 상한과 실제 병력 간 대응은 시각 정책 데이터로 관리한다. 정확한 병력은 숫자로 별도 표시한다.
돌격·피격·패주 효과는 실제 코어 상태/사건을 사용하고, 장식 애니메이션이 판정을 만들지 않는다.
누락 리소스에는 기존 도형 대체 표시를 유지한다.

## 6. UI 첫 적용 기준
- 선택 부대 이름, 병종, 체력·사기·응집도 각각 표시.
- Q: 부대 선택 → 목표 지정 → 돌격 실행 → 진행 → 결과.
- 실패 이유와 해결 행동, 쿨다운 초 단위 표시.
- 상태바와 라벨은 별도 오버레이에서 겹침 완화. 전투 좌표를 이동시켜 겹침을 해결하지 않는다.
- 하단 HUD는 화면 높이 약 18~22%를 출발점으로 테스트한다.
- 전멸 시 테스트 재시작 안내. 정식 승리·패배 규칙 구현으로 표기하지 않는다.
- 테스트 설정과 로그는 접을 수 있는 보조 패널로 분리한다.

## 7. 제작·검수 파이프라인
1. 동일 화풍의 무장·기병·창병 개별 투명 샘플 생성.
2. 발 위치·윤곽·무기 방향·잔여 배경·비율 보정.
3. 실제 표시 크기로 축소해 병종과 소속 식별 확인.
4. 정적 리소스를 표시 계층에 연결하고 투영/역변환 검증.
5. 방향·애니메이션 확장 후 아틀라스 패킹.
6. 다부대 가림, 선택, 스킬 명중, 패주, 전멸 상황 확인.
7. 같은 입력의 코어 상태/리플레이가 표시 변경 전후 동일한지 검증.
8. typecheck/test/build와 실제 브라우저 조작 검수. 실행하지 않은 검수는 미실행으로 기록.

## 8. 완료와 미완료
이 문서는 제작 기준이며 구현 완료 보고가 아니다.
현재 전투 화면은 도형 기반 Phaser 데모. 이 문서 작성만으로 쿼터뷰·리소스·새 UI가 적용되지 않는다.
생성 샘플은 정적 초안이며 방향별 스프라이트나 애니메이션 완성품이 아니다.
후속 첫 구현 단위: 투영/역변환 + 정적 3종 + 깊이 정렬 + 기존 명령 회귀 검증.
