# 쿼터뷰 정적 리소스 적용 v0.1
2026-10-26
## 적용
- 화면 투영과 역변환을 클라이언트에 분리. 카메라 좌표 변환 후 명령 목적지를 코어 정수 좌표로 환산.
- 범위 원, 이동 방향, 실제 돌격 경로, 적중 표시를 동일 투영으로 표시.
- AI 생성 투명 PNG 2172×724를 원본 그대로 724×724 세 프레임으로 표시. 원본 생성 경로: exec-1f0e2cf5-dddf-4b28-ad67-6af912b75bc3.png.
- 기병·창병은 최대 8개의 장식적 병사 이미지, 무장은 백마 이미지. 모든 이미지는 고정 방향 정적 초안.
- 보병·궁병·전멸 부대는 도형 대체 표시. 샘플 복식 색과 무관하게 소속은 군기·발 아래 표시·라벨로 구분.
- 발 위치를 기준으로 깊이 정렬. 기존 명령/HUD 유지, 제목과 기초 팔레트 변경.
- battle-core 및 전투 데이터 변경 없음.
## 검증
- npm run typecheck: 통과
- npm test: 175개 통과 (투영/역변환/범위 표시 신규 3개)
- npm run build: 통과
- npm run sim:smoke: 두 1000tick 시나리오 replayMatches=true
- npm run format:check: 통과
- Playwright 테스트 클릭 좌표를 새 투영에 맞춰 변경.
- 실제 브라우저 검수 미실행: Chromium 다운로드 ZIP 손상으로 설치 실패. 이전 버전 브라우저 보고서는 이번 변경의 검증이 아님.
## 제한 및 후속
- 검토용 PR이며 실제 브라우저 확인 전 병합 보류.
- 전투 화면 시안의 완성 배경·하단 군령 UI·애니메이션은 아직 미적용.
- 한 방향 이미지이므로 이동 방향과 그림 방향이 다를 수 있음. 군기와 방향선이 실제 소속/방향을 보조.
- 원본을 data URI TS로 포함한 임시 배포 방식. JS 약 3.06MB(이전 약 1.36MB). 후속으로 정적 PNG+atlas 및 캐시 분리 필요.
- 생성 이미지의 개별 기준점·무기 여백·축소 가독성·알파 가장자리 시각 검수 필요. 실제 고증 검증 미완료.
- 접전 시 라벨 겹침 완화와 진형별 병사 배치 개선 필요.
- 브라우저에서 선택/우클릭 이동/Q 적 지정/충돌/카메라 이동 후 입력/초기화/90초 리플레이를 검증할 것.
