# 국가 공유 시야 · 시연 v0.1

## 채택한 사용자 결정

- 같은 국가의 모든 플레이어가 부대 시야를 공유한다.
- 시야 밖 적은 마지막 위치와 관측 tick만 표시한다.
- 모든 부대의 반경은 10타일로 시작하며, 운영 밸런스가 아닌 조절 가능한 실험값으로 관리한다.

## 관측과 기억

`fog_config.v1.json`의 `radiusTiles`가 온라인 경기와 전투 코어의 시야 반경을 정한다. 수정 후 서버를 다시 시작한다. 클라이언트가 보낸 옵션으로 반경을 바꿀 수 없다. 살아 있는 아군 부대의 중심에서 원형 반경을 합치며 정확히 경계에 있는 적도 보인다. 전멸한 부대는 시야를 제공하지 않는다.

서버는 매 tick 국가별 마지막 관측을 기록한다. 적이 사라지면 현재 위치·HP·병력·사기·전열·행동을 갱신해 보내지 않는다. 이전 위치와 마지막으로 보인 tick만 보존한다. 새로고침·재접속과 같은 국가의 다른 참가자도 같은 기억을 공유한다. 재관측 시 최신 상태를 보여 주며, 격파를 직접 관측하면 마지막 위치 표시는 제거한다. 이번 시연에는 기억의 자동 만료 시간을 두지 않는다.

## 전송 경계

| 데이터 | 아군 | 현재 보이는 적 | 시야 밖 적 |
| --- | --- | --- | --- |
| 부대 위치·병력·HP·사기·전열·태세·진형·행동 상태 | 현재 값 | 현재 값 | 전송하지 않음 |
| 마지막 위치·관측 tick | 불필요 | 현재 관측으로 갱신 | 이전 관측값만 전송 |
| 장수 HUD | 같은 국가의 장수 | 전송하지 않음 | 전송하지 않음 |
| 명령·목표 ID·AI anchor·개인 성장 후보·난수 seed | 전송하지 않음 | 전송하지 않음 | 전송하지 않음 |
| 전투 사건 | 표시용 필드만 | 보이는 참조만 | 숨겨진 참조가 있으면 제외 |

전체 `BattleState`는 서버에 남는다. 별도 `BattleView`를 국가마다 만들고 그 관측 상태에 대해서만 스냅샷·델타·해시를 보낸다. 같은 국가의 세 참가자는 같은 tick에 같은 해시를 보며, 서로 다른 국가는 해시가 달라질 수 있다. 양쪽에서 동시에 보이는 부대의 현재 값은 동일해야 한다.

## 명령과 기본 교전

시야 밖 적 ID를 직접 넣은 ATTACK·Q 명령은 서버 경계와 코어에서 `TARGET_NOT_VISIBLE`로 거부한다. 자동 목표 획득도 공유 시야를 따른다. 기존 ATTACK 대상이 시야를 벗어나면 기존 코어의 목표 상실/복귀 흐름을 사용해 보이지 않는 현재 위치를 추적하지 않는다. 지상 이동·공격 이동은 계속 가능하다. 이미 승인된 Q의 고정 돌격 궤적과 충돌 계산은 기존 규칙을 유지한다.

코어의 시야 정책은 순수 TypeScript의 선택적 설정이다. 온라인 서버가 해당 설정을 주입한다. 기존 로컬 전투 데모는 시야 설정을 주입하지 않아 기존 전역 관측 시연을 유지한다.

## 검증과 남은 범위

순수 코어·서버 단위 검사에서 국가 공유, 경계 거리, 사망한 관측자 제외, 기억 고정·재관측, 숨겨진 상태/사건 참조 제외, ATTACK/Q 거부, 자동 교전/추적 중단을 검증한다. 실제 브라우저에서는 적의 이탈·기억 표시·강제 대상 지정 거부·재접속·재관측과 같은 국가 해시 일치를 검사한다. 900tick 검사는 국가별 해시를 대조한다.

지형/높이 차폐·은폐/정찰 스킬·탐색 지형 기억·온라인 사건 로그 전체 재전송·운영 밸런스는 후속 범위다.
