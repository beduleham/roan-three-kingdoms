# 국가 경기에서 확정이 필요한 사항

이번 구현은 흐름을 검증할 수 있도록 별도 실험 프로필로 제공한다. 기존 작은 거점 시연에서 승인한 수치는 변경하지 않는다. 아래 항목에 대한 승인·플레이테스트 없이 정식 밸런스로 승격하지 않는다.

| 항목             | 현재 실험 가정                                             | 결정할 내용                                                                            |
| ---------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 배치·국가 공정성 | 본영3·외곽3·중앙성1, 평면24×13타일                         | 실제 지형, 이동 거리, 접근 경로, 본영 점령/보급 제한                                   |
| 참가 인원        | 각 국가 인간1명 이상, 총3~9명·나머지 기본 AI               | 인간1~2명일 때 AI 국가를 허용할지, 좌석/국가 선택 UI                                   |
| 보급             | 초기50, 아군 거점당5초에2, 최대5명×비용2, 편성10명/40, 3초 | 비용·속도·소유 거점 간 자원 공유, 편성 부대 최대25, 작업 중 이탈/상실의 즉시 취소 여부 |
| 기여·관직        | 유효 적 HP 피해+현장 점령/주둔, 기존 잠정 관직표           | 본영 주둔 보상을 계속 지급할지, 방어/지원/다수 참여 정규화·중복 방지 정책, 승진 임계값 |
| XP               | 별도40레벨 곡선, 피해·점령·주둔 보상                       | 15분 일반33~35·상위38~40 목표에 맞는 곡선/보상 실험                                    |
| 증강             | 기존3개 효과×3식별자의 후보9개, 선택7회                    | 정식 후보군·해금·재등장·중첩·중복 선택 규칙; 현재 복제 효과는 정식 콘텐츠 아님         |
| 종전             | 15/18/21분, 10%/5%, 10분 이후4거점45초                     | 연장·천하통일 조건 및 빈도, 중단/기권 정책                                             |
| 순위             | 모든 인간 공적↓·기여↓·ID↑, AI 제외                         | 기여 지표 정의·동점 처리·중단 순위 표시 정책                                           |

반복 AI 실행은 명령·상태 재현성 및 한도/완주 검사다. 인간 전략·스킬·증강 선택·보급 전술을 재현하지 않으며, 국가별 승률의 균형을 입증하지 않는다. 단순 기본 AI와 임시 지형에서 특정 국가가 계속 승리하면 이를 균형 확인으로 해석하지 않는다.
