# Phase 7 — 근거와 변경 후보

**제안 반영 승인 후:** 적용 기준은 [Phase7 규칙 v1](PHASE7_POLICY_v1.md), 새 검증 결과는 [실행 보고서](../demo/phase7-policy-v1-validation.md)에 기록했다. 아래 본문은 제안 당시의 이력이며 지도/인간 밸런스 인수는 아직 남아 있다.

## 1. 국가·지도

생산 지도에서 시작 위치6순열×기본 AI 배정2종×시드2개=24경기를 실행하고 각각 재실행했다. 국가 이름별 승리는 각4회여도 생산 AI의 물리적 북서 위치가8승, 북동4승, 남쪽0승이다. 비교용 가까운 거점/중앙성 역할 배정은 북동12승으로 더 편향됐다. 이름별 승률만 보고 균형을 선언하지 않는다. 이 비교용 정책은 채택하지 않는다.

지도 후보 `experiments/phase7/layout-candidate.v1.json`은 중앙성 주위의 세 시작 위치·외곽을 회전 대칭에 가깝게 배치하고, 초기 부대 대형과 역할의 진행 방향도 같이 회전한다. 정수 좌표 반올림이 있어 완전한 기하 대칭은 아니다. 이 후보도 별도6순열·재실행으로 검사했다. 위쪽 시작 위치0승·남서3승·남동3승으로 여전히 편향됐다. 지도·부대 대형·역할 경로를 함께 바꾼 묶음 후보이므로 각각의 원인을 분리해 증명한 결과도 아니다. 생산 기본값으로 채택하지 않는다.

**추천:** 기본 지형·진입로·목표 배정의 효과를 분리한 뒤 인간 자리 교대 플레이테스트를 진행한다. 현재 가까운 거점 정책을 생산 AI에 바로 넣지 않는다.

## 2. 성장·본영 보상

현재 본영 하나에서 유효 병력으로 주둔만 하면15분에 XP3600·12레벨·공적5400·교위·보급410, 증강 기회2회다. 21분에도15레벨이다. 두 부대가 같은 거점에 있어도 플레이어 보상은 한 번이다. 이 계산은 실제 진행 함수의 고정 주둔 fixture와 대조했다.

천하통일을 시험에서만21분 이후로 미뤄15분까지 관측한 두 기본 AI 경기에서도 종료 레벨은1~13 범위다. 무장 스킬·보급·증강을 쓰는 인간 경기 표본이 아니므로 정식 XP 배율을 이 결과에서 바로 확정하지 않는다.

**추천:** 본영 대기는 보급 회복 수단으로 두고, 단순 본영 주둔 XP/공적의 폐지 또는 축소를 검토한다. 전방 점령·유효 교전·방어·지원 결과별 XP를 먼저 측정한 뒤33~35/38~40 목표에 맞춰 곡선을 정한다. 전체 XP를 일괄 배수로 올려 본영 대기까지 목표 레벨에 도달시키는 방식은 피한다.

## 3. 관직·충원

| 관직   | 병력 상한 | 시작 부대 둘을 유지할 때 도달 가능 | 차이 |
| ------ | --------: | ---------------------------------: | ---: |
| 군후   |        40 |                                 40 |    0 |
| 군사마 |        50 |                                 40 |   10 |
| 교위   |        60 |                                 60 |    0 |
| 중랑장 |        75 |                                 65 |   10 |
| 장군   |        90 |                                 90 |    0 |

시작 두 부대의 개별 최대 병력은20, 새 편성 부대는25다. 부대를 잃고 다시 편성하는 경우는 위 계산에서 제외했다. 장군4/90까지 도달하는 최소 보급 비용은140, 순차 작업 시간만의 하한은24초다. 승진·수입 대기·이동·피해는 이 하한에 포함하지 않는다.

**추천 후보:** 군사마부터 개별 부대 수용 상한을25로 늘리되 현재 병력/HP는 지급하지 않고, 실제 거점 보급으로 채운다. 군후2/40과 관직별 총합 한도는 유지한다. 최대 병력 대비 비율을 쓰는 R 등은 이 변경과 함께 회귀 검사해야 한다. 아직 생산 규칙에 적용하지 않았다.

### 전멸 후 복구

현재 충원/편성은 자기 유효 부대가 아군 거점에 있어야 한다. 두 부대가 모두 전멸하면 보급과 보유 본영이 있어도 새 부대 편성이 막힌다. 이 경계는 자동 검사로 재현했다. 이것을 전투 패배의 확정된 탈락 규칙으로 채택한 것은 아니다.

**추천 후보:** 죽은 부대를 되살리는 충원은 계속 금지하되, 전멸한 플레이어가 보유 본영에서 수동으로 신규 편성을 요청할 수 있게 한다. 무료 자동 지급은 하지 않고 비용·대기 시간·복구 후 병력·본영 상실 시 처리는 별도로 정한다. 아직 생산 규칙은 바꾸지 않았다.

## 4. 피해 공적·지원/방어

현재 유효 HP 피해 총량은 과잉 지급하지 않지만, 같은 표적에 여러 공격이 동시에 들어오면 이벤트 배열에서 먼저 처리된 공격자부터 남은 유효 피해를 받는다. 예를 들어 실제 피해90000에 청200000·적100000 공격이 있으면 순서에 따라 청90000/적0 또는 청0/적90000이다.

별도 `allocateDamageProportionally` 후보는 실제90000을 청60000/적30000으로 정수 비례 배분한다. 남는1 단위는 잔여 비율→actor ID 순으로 처리한다. 순서 불변·총량 보존·초과 피해 제한·안정된 사건 ID 중복 제거를 단위 검사했다. 실제 엔진의 사건 식별자와 연결하기 전에는 생산 보상 함수로 쓰지 않는다.

**추천:** 이 비례 배분안을 채택할지 결정한다. 지원·방어는 실제 피해 방지·전선/거점 유지 결과와 중복 제거의 정의부터 정하고, 별도 지표로 관측한 뒤 공적 정규화/가중치를 검증한다. 현재 원시 스킬 시전 횟수에 공적을 주지 않는다.

## 5. 증강9개 후보

생산 후보9개는 실제로3개 효과의 복제다. 후보 제시는 시드 추첨이 아니라 자격을 갖춘 미선택 ID의 정렬순3개다. 이전 보고서의 시드 추첨 관련 설명은 소스 점검에 따라 정정했다.

`experiments/phase7/augment-candidates.v1.json`은 기존 엔진이 지원하는 효과를 다른 스킬·발동 조건·대상으로 조합한 **시험용9개**다. 생산 방은 이 파일을 읽지 않는다.

| 발동                               | 공격     | 이동     | 전열 보호        |
| ---------------------------------- | -------- | -------- | ---------------- |
| Q 실제 충돌 성공, 해당 돌격 부대   | +15%·3초 | +10%·3초 | 피해 감소20%·3초 |
| W 시전, 실제 대상 부대             | +15%·6초 | +10%·6초 | 피해 감소20%·6초 |
| R 시전, 실제 대상 부대·15레벨 제한 | +15%·6초 | +10%·6초 | 피해 감소20%·6초 |

수치는 기존 효과의 시험값을 재사용한 가설이며 정식 값이 아니다. 9개 각각의 발동·다른 스킬 거부·만료, 총7회 선택·R 후보 해금을 검사했다. 각 정의의 중첩은 갱신1회이며 여러 정의 간 합산에는 기존 엔진의 공격/속도 최대100%, 전열 피해 감소 최대30% 제한이 적용된다. 스킬별 발동을 다르게 한 것이지 정식 장수9종을 만든 것은 아니다.

**추천:** 동일 효과 복제 후보를 정식 콘텐츠로 부르지 않는다. 후보 구성·무작위/고정 제시·같은 효과군 선택 허용·합산 제한을 정한 뒤 실제 선택률과 역할별 효용을 비교한다. 지금은 복제 없는9개 후보의 기능 시험까지만 했다.

## 적용 경계

이번에 실제 게임 화면에 반영한 개선은 증강 효과와 지속시간을 서버 정의에서 읽어 표시하는 것이다. 새 지도·AI 목표 정책·XP/보급/공적·관직 상한 확장·9개 후보·비례 피해 공적은 모두 미확정 실험/제안으로 유지한다. Phase8 화면 제작에는 진입하지 않는다.
