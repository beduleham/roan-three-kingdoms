# Phase 7 기준 규칙 v1

상태: 사용자 요청으로 제안 반영을 승인받아 **구현 기준을 정하고 자동 검증한 버전**이다. 지도 공정성과 인간 경기의 성장 분포까지 인수한 정식 경쟁 밸런스는 아니다. 실제 선택률·지원 기여·전략적 판단의 밀도는 인간 플레이테스트로 확인한다. 2026-11-01 사용자 지시로 인간 인수는 보류하고 Phase8 화면 개발에 진입했다. 미검증 항목을 통과로 간주하지 않는다.

## 프로필과 적용 범위

`battle_national` / `online.html?mode=national`에 적용한다. `national_demo.v1.json`의 `policy.version=phase7-v1`, 별도 `national_augments.v1.json`이 기준이다. 작은 거점 경기/기존1대1·3대3의 규칙은 유지한다. 이전 국가 프로필은 `experiments/phase7/legacy-national.v1.json`으로 보존하며, 기존 진단 재현 도구는 그 파일을 읽는다.

## 확정한 구현 규약

- 본영 단순 주둔에는 XP/공적을 지급하지 않는다. 보급 수입은 유지한다. 적 본영을 실제 점령한 보상은 허용하지만 이후 본영 주둔 반복 보상은 없다.
- 개방된 외곽/중앙성의 실제 점령은 XP100/공적600, 현장 유지와 소유권을 유지한 경합 방어는5초당XP20/공적30이다. 같은 거점에 두 부대가 있어도 플레이어당 한 번이다. 별도 방어 보너스를 중복 지급하지 않는다. 경합 중 국가 점수와 보급 수입은 종전대로 멈춘다.
- 관직별 총합은2/40→2/50→3/60→3/75→4/90을 유지한다. 군후의 부대별 최대20명, 군사마부터25명으로 수용 상한만 확대한다. 승진으로 현재 병력/HP를 지급하지 않는다. 추가 병력은 거점에서 실제 보급을 소비해야 한다.
- 기존 초기 보급50, 아군 거점당5초에2, 충원 최대5명·1명당2, 신규 편성10명·비용40·3초를 유지한다. 군후 신규 부대도 최대20명이다. 참가자당 작업1개, 요청과 완료 시 지휘 상한을 검사한다.
- 일반 충원/편성은 비경합 아군 거점의 자기 유효 부대가 필요하다. 사망 부대 충원은 계속 금지한다.
- 자기 살아 있는 부대가 하나도 없으면 **자기 국가의 보유 본영**에서 수동 신규 편성을 요청할 수 있다. 비용40·시간3초·병력10을 재사용하며 무료 자동 지급은 없다. 본영 상실/경합/적 점령 진행 시 요청·완료를 거부한다. 다른 거점으로 원격 복구하지 않으며 본영 재탈환까지 막힐 수 있다. 자동 기권/패배 규칙은 추가하지 않는다.
- 완료 시 조건을 다시 검사한다. 취소·상한 부족·종전·이탈 중단으로 미완료된 작업은 비용을 한 번 환불하고 큐를 비운다. 죽은 부대는 선택 목록/전장에서 제외하며 새 부대에는 새ID를 부여한다. 장수는 기존 재출전·수동 재배속 규칙을 따른다.

## 유효 피해 공적

일반 공격으로 적 부대에 발생한 실제 HP 손실을 예산으로 사용한다. 장수에게 분배된 HP, 전열/사기 수치, 시전 횟수는 이 지표에 섞지 않는다. 각 공격의 제안 피해에 비례해 정수 배분하고, 남은1단위는 잔여 비율→actor ID 순으로 처리한다. 예산90000·제안200000/100000이면60000/30000이다.

코어는 한 전투tick에 공격자/표적당 일반 공격 사건을 최대1개 발생시킨다. `tick/type/actor/target`을 안정된 사건 식별자로 사용해 중복을 제거한다. 다른tick·아군 피해는 제외하고 상충하는 중복은 내부 오류로 거부한다. 전체tick 재처리도 거부한다. 계산은 BigInt를 사용하고 안전한 정수로만 반환한다.

피해10000 hpMilli당XP1,5000당공적1, 기존 관직 공적 임계값은 유지한다. 원시 사건 수에35/25/20/20 가중치를 곱하지 않는다. 별도 지원 점수는 아직 도입하지 않는다.

## 성장 곡선

40개 정수 XP 임계값을 채택했다. 기존 보상을 일괄 배수로 올리지 않고 본영 대기를 제외한 활동량 기준 원장에 맞춰 곡선을 보정했다.

| 가정한 활동 원장                               |   XP | 레벨 |
| ---------------------------------------------- | ---: | ---: |
| 전선 방어: 유지156회·점령1회·유효 피해300만    | 3520 |   33 |
| 전선 주력: 유지144회·점령2회·유효 피해700만    | 3780 |   34 |
| 전선 우수: 유지156회·점령3회·유효 피해700만    | 4120 |   35 |
| 상위 활동: 유지180회·점령3회·유효 피해900만    | 4800 |   38 |
| 최상위 활동: 유지190회·점령4회·유효 피해1400만 | 5600 |   40 |

이것은 **활동량 가정의 보정 결과이며 인간의 실제 일반/상위 분포를 측정한 결과가 아니다.** 방어 사례는 실제 보상 함수를 통한 원장 재생으로3520XP/33레벨을 확인했다. 본영 대기15분은1레벨이다. 여러 거점 유지 횟수의 합이 단일 거점의 주기 수를 넘을 수 있다.

## 증강·AI

Q 실제 충돌·W 실제 대상·R 실제 대상에 공격/기동/전열 보호를 적용하는 서로 다른9개 정의를 사용한다. 이전3효과의 복제 후보를 제거했다. Q 공격15%/기동10%/전열 피해 감소20%는3초, W/R은 각각 같은 개별 값으로6초이며 기존 시험값을 재사용했다. R 스킬/후보는15레벨 제한이다. 장수9종을 만든 것은 아니다.

5/10/16/22/28/34/38레벨에서 적격·미선택 후보3개 중 인간이1개를 선택한다. 서버가 경기마다 생성한seed와 플레이어·체크포인트·증강ID의 순수 정수 해시로 후보를 정한다. 동일seed/입력은 재현되고 순회 순서나 별도 RNG 소비에 영향받지 않는다. 서버seed는 생성 옵션으로 받거나 전송하지 않는다. 보류 중인 후보는 유지한다.

동일 증강 재선택은 금지하고 다른 정의의 동일 효과 합산은 허용한다. 같은 정의는1중첩·기간 갱신이다. 기존 공격/속도 보너스100%, 전열 피해 감소30% 상한을 유지한다. AI는 증강·Q/W/R·전략 후퇴·진형을 자율 선택하지 않는다.

기존 기본 AI의 전략 목표 배정/경로 선택은 유지한다. 정밀하게 같은 위협·거리의 목표만 ID 사전순 대신seed로 비교하며 명시한 인간 공격 목표는 우선한다. 실패한 균등 역할/근거리 정책이나 회전형 지도 후보를 기본값으로 채택하지 않았다. 지도 좌표·2/5분 개방·15/18/21분·10%/5% 연장·10분 이후45초 천하통일은 유지한다.

## 인수와 배포

[새 실행 보고서](../demo/phase7-policy-v1-validation.md)를 기준으로 확인한다. 이번 기준은 구현 승인 범위의 v1이며, 위치 공정성·인간 레벨 분포·증강 효용·지원 기여 정규화의 인수는 남아 있다. 따라서 `experimental`/`experimental-not-balance-validated` 표기를 유지한다.

Render Manual Deploy → Deploy latest commit 후 새 방에서 검증한다. 진행 중 방을 마이그레이션하지 않는다. 실제 플레이에는 국가별 인간1명 이상이 필요하다. Google 로그인은 계속 보류한다.
