# Phase 7 — 인간 플레이테스트 기록표

자동 대전은 재현성과 구조적 편향을 찾기 위한 도구다. 재미, 낮은 APM에서의 전략적 선택, 보급/증강 선택의 매력은 인간 플레이로 확인한다. 승인한 Phase7 v1 구현은 Live에서 짧은 외부 검사를 통과했다. 이 문서는 정식 경쟁 밸런스 인수 절차이며, 인간 결과가 없는 항목을 완료로 표시하지 않는다.

## 진행

- 국가별 인간1명 이상으로3~9명 모집한다. 같은 팀/전략 조합을 유지하면서 다음 경기에는 국가 시작 위치를 바꾼다. 참가자와 지도 위치의 효과를 구분한다.
- 모든 참가자가 공통으로 이해할 규칙: 자동 기본 교전, 직접 이동 목표·Q/W/R·후퇴·진형·증강 선택, 보급 소비, 15/18/21분 판정과 천하통일.
- 변경은 한 번에 한 축만 비교한다. 지도/AI 배정과 XP/보급/증강을 한꺼번에 바꾸면 원인을 해석하지 않는다.
- 전략적으로 바빴는지 확인한다: 의미 있는 목표 변경, 교전 진입/이탈 판단, 충원/편성 선택, 증강 선택 이유를 간단히 기록한다. 클릭 횟수가 높다는 이유만으로 성공 판정을 내리지 않는다.
- 증강을 선택하지 않은 이유, 병력이 없어서 할 일이 사라진 시점, 점령·종료 규칙이 이해되지 않은 시점을 기록한다. 패배 팀도 선택·성장의 여지가 있었는지 확인한다.

## 경기별 기록

| 항목                                                       | 기록 |
| ---------------------------------------------------------- | ---- |
| 경기 ID / 빌드 / 실험 프로필                               |      |
| 참가자 익명 ID / 국가 / 시작 위치 / 주요 역할              |      |
| 목표 변경·교전·후퇴를 결정한 이유                          |      |
| 5/10/15분 및 종료 레벨·XP·공적·관직                        |      |
| 거점 경쟁·유효 피해·방어·지원 기여 사례                    |      |
| 보급 첫 사용 / 충원·편성 횟수 / 취소 이유 / 자원 부족·과잉 |      |
| 각 증강 선택 시각 / 후보 / 선택·보류 이유                  |      |
| 병력 전멸 후 대기 시간 / 복구 가능 여부                    |      |
| 국가 점수 / 종료 시각·이유 / 전체 인간 순위                |      |
| 불공정하게 느껴진 위치·순위·자동 행동과 재현 절차          |      |
| 전략 판단의 밀도 / 불필요한 조작 / 다음 경기에서 바꿀 선택 |      |

지원·방어 기여는 아직 공적 점수로 합산하지 않는다. 실제 감소시킨 피해·유지한 전선·거점 경합·동료 생존처럼 결과가 있는 사례와 원시 이벤트를 먼저 모은다. 같은 피해/지원 사건을 여러 지표로 중복 보상하거나 원시 사건 수에35/25/20/20 가중치를 바로 곱하지 않는다.

전멸 후 무조건 자동 재편성, AI의 스킬·전략 후퇴·진형 자율 선택은 현재 합의에 포함되지 않는다. 이런 복구/자율권의 변경이 필요하면 별도 기획으로 검토한다.

## 현재 빌드에서 기록하는 방법

1. 최신 변경을 수동 배포한 뒤 [국가 경기](https://roan-three-kingdoms.onrender.com/online.html?mode=national)에서 새 초대 전용 경기를 만든다. 실제 사람3명 이상이 각 국가로 입장한다. 같은 사람이 여러 브라우저를 연 것은 동기화 검사이며 인간3명 표본으로 세지 않는다.
2. 처음3명의 입장 순서는 청국(NW)→적국(NE)→녹국(남쪽)이다. 다음 경기에는 사람의 입장 순서를 바꿔 위치를 교대한다. 첫3경기는 동일 전략/역할을 유지해 위치만 비교하고, 역할 교대는 별도 묶음으로 기록한다. 3경기는 진단 시작 단위이며 통계적 공정성 보증 표본 수가 아니다.
3. 성장·보급 패널의 기록 메모에 배포 커밋, 익명 참가자 ID, 역할, 중요한 선택 이유를 적는다. 실제로 사용한 Q/W/R·후퇴·진형·증강 선택과 보급 소비를 기록한다. 이벤트 수만으로 지원·방어 점수를 산정하지 않는다.
4. 종료 후 **내 경기 기록 저장 (JSON)**을 눌러 각자의 파일을 보관한다. 재접속/새로고침 전에도 저장한다. 새로고침은 기록을 초기화하며 서버 리플레이/자동 업로드가 아니다. 새 방으로 가면 이전 방 기록도 교체된다.
5. 30초 간격의 실제 관측 tick을 사용한다. 정확한5/10/15분 tick이 없으면 가까운 관측값과 차이를 적고 누락을 보간하지 않는다. 단축 시계 fixture와 운영15/18/21분 경기를 섞지 않는다. 제출 명령·서버 입장 검사 응답은 스킬 효과/작업 완료 자체의 증거가 아니다.
6. 같은 게임 ID의 기록을 모아 결과 일치, 각자의 성장·실제 선택, 전멸 후 복구 기회, 판단 이유를 비교한다. 초대 키·계정 토큰·다른 사람의 개인정보를 메모에 넣지 않는다.

현재 파일은 본인 성장·보급·공개 거점/결과와 관측된 후보/선택·작업 변화를 담는다. 다른 참가자의 비공개 성장·적 기억 위치·초대/재접속 토큰은 내보내지 않는다. 지원의 인과 효과, 실제 재미, 입력이 인간인지 여부는 자동 판정하지 않는다. 각 목록2000개 제한 및 누락 개수를 내보내므로 잘린 기록을 완전한 경기라고 주장하지 않는다.

[최신 인수 현황과 대조 실험](../demo/phase7-acceptance-status.md)을 함께 읽는다. 단발 복구 자동 대전의 남쪽0승과 반복 유료 복구 대전의 남쪽 승리는 서로 다른 행동 조건이다. 어느 하나를 인간 밸런스의 확정 근거로 사용하지 않는다.
