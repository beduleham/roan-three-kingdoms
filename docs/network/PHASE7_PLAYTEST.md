# Phase 7 — 인간 플레이테스트 기록표

자동 대전은 재현성과 구조적 편향을 찾기 위한 도구다. 재미, 낮은 APM에서의 전략적 선택, 보급/증강 선택의 매력은 인간 플레이로 확인한다. 현재 국가 경기 실험 수치를 확정하거나 아래 후보를 Live에 적용한 문서가 아니다.

## 진행

- 국가별 인간1명 이상으로3~9명 모집한다. 같은 팀/전략 조합을 유지하면서 다음 경기에는 국가 시작 위치를 바꾼다. 참가자와 지도 위치의 효과를 구분한다.
- 모든 참가자가 공통으로 이해할 규칙: 자동 기본 교전, 직접 이동 목표·Q/W/R·후퇴·진형·증강 선택, 보급 소비, 15/18/21분 판정과 천하통일.
- 변경은 한 번에 한 축만 비교한다. 지도/AI 배정과 XP/보급/증강을 한꺼번에 바꾸면 원인을 해석하지 않는다.
- 전략적으로 바빴는지 확인한다: 의미 있는 목표 변경, 교전 진입/이탈 판단, 충원/편성 선택, 증강 선택 이유를 간단히 기록한다. 클릭 횟수가 높다는 이유만으로 성공 판정을 내리지 않는다.
- 증강을 선택하지 않은 이유, 병력이 없어서 할 일이 사라진 시점, 점령·종료 규칙이 이해되지 않은 시점을 기록한다. 패배 팀도 선택·성장의 여지가 있었는지 확인한다.

## 경기별 기록

| 항목                                                       | 기록 |
| ---------------------------------------------------------- | ---- |
| 경기 ID / 빌드 / 실험 프로필                               |      |
| 참가자 익명 ID / 국가 / 시작 위치 / 주요 역할              |      |
| 목표 변경·교전·후퇴를 결정한 이유                          |      |
| 5/10/15분 및 종료 레벨·XP·공적·관직                        |      |
| 거점 경쟁·유효 피해·방어·지원 기여 사례                    |      |
| 보급 첫 사용 / 충원·편성 횟수 / 취소 이유 / 자원 부족·과잉 |      |
| 각 증강 선택 시각 / 후보 / 선택·보류 이유                  |      |
| 병력 전멸 후 대기 시간 / 복구 가능 여부                    |      |
| 국가 점수 / 종료 시각·이유 / 전체 인간 순위                |      |
| 불공정하게 느껴진 위치·순위·자동 행동과 재현 절차          |      |
| 전략 판단의 밀도 / 불필요한 조작 / 다음 경기에서 바꿀 선택 |      |

지원·방어 기여는 아직 공적 점수로 합산하지 않는다. 실제 감소시킨 피해·유지한 전선·거점 경합·동료 생존처럼 결과가 있는 사례와 원시 이벤트를 먼저 모은다. 같은 피해/지원 사건을 여러 지표로 중복 보상하거나 원시 사건 수에35/25/20/20 가중치를 바로 곱하지 않는다.

전멸 후 무조건 자동 재편성, AI의 스킬·전략 후퇴·진형 자율 선택은 현재 합의에 포함되지 않는다. 이런 복구/자율권의 변경이 필요하면 별도 기획으로 검토한다.
