# Phase 6-1 — 작은 온라인 거점 경기 (실험)

범위: 국가 경기 상태 → 점령 → 국가 점수 → 종료/결과 → 새 경기. `battle_objectives` 방과 `/online.html?mode=objectives`에서 실행한다. 기존 1대1/3대3 전투 시연의 규칙은 유지한다.

## 운영 흐름

1. 거점 경기 링크에서 초대 전용 경기를 만들고 다른 브라우저에 초대한다.
2. blue/red 각 한 명이 입장하면 로비장만 시작할 수 있다. 그 전에는 tick과 점수가 진행되지 않는다.
3. 부대를 거점 원 안으로 이동한다. 서버가 실제 부대 상태로 점령을 계산한다. 별도 CAPTURE/점수 변경 API는 없다.
4. 목표 점수 또는 시간 제한으로 종료한다. 양측에 같은 결과를 전달하고 서버 명령 접수·tick 진행·신규 입장을 막는다.
5. 결과를 본 뒤 새 초대 경기를 만들 수 있다. 상대는 새 링크로 다시 입장한다. 이전 경기의 상태나 토큰을 이어 쓰지 않는다.

## 확정이 아닌 시연용 가정

`objective_demo.v1.json`은 `experimental: true`인 별도 실험 프로필이다. 정식 15/18/21분 국가 경기의 수치나 밸런스를 확정한 것이 아니다. 초기 2국가×1명, 중립 거점 3개로 흐름만 검증한다.

| 항목 | 현재 실험값/동작 | 결정할 사항 |
|---|---|---|
| 점령 반경/시간 | 1.5타일 안에서 3초 연속 단독 국가 존재 | 반경·시간 및 병력/부대 수 가중 여부 |
| 점령 자격 | 생존, 사기·전열 양수, 패주·붕괴·후퇴가 아닌 부대. 교전 중 참여 가능 | 교전·후퇴·상태 이상별 참여 정책 |
| 경합/이탈 | 양국이 함께 있거나 점령자가 떠나면 진행 초기화. 아군 여러 부대는 한 국가로 계산 | 진행 보존·감소·수적 우위 허용 여부 |
| 소유권 전환 | 중립/적 소유 거점 모두 같은 시간에 직접 전환 | 중립화 후 재점령의 2단계 여부 |
| 점수 | 서버 전투 tick 기준 5초마다 외곽 1점, 중앙 2점. 소유 유지 시 무인 거점도 수입. 적 점령 참여가 있으면 이전 소유자의 수입 중단 | 정식 점수 시작 시점·수입 정지 조건 |
| 개방 | 외곽 즉시, 중앙 30초 | 기존 정식 설계 외곽 2분/중앙 5분과의 통합 |
| 종료 | 12점 먼저 도달 또는 180초에 높은 점수 승리. 양국 점수 반영 후 동일 최고점이면 무승부 | 목표 점수·시간·연장·동률 처리 |
| 정보 공개 | 거점 위치·소유권·진행·경합·점수는 공개 전략 정보. 적 부대 정보는 기존 국가 시야로 제한 | 시야 밖 소유권/경합/점령 진행 공개 여부 |
| 접속 이탈 | 일시 단절은 기존 30초 좌석 예약 동안 전체 경기 tick/시간/점수 정지. 자발적 나가기 또는 예약 만료는 승패 없는 중단 | 기권패·대체 AI·재입장·운영 제한 |

경기 시간은 벽시계가 아니라 실제 진행한 전투 tick이다. 같은 점수 처리 tick에 동시에 목표를 넘으면 모든 국가의 수입을 적용한 뒤 높은 점수가 승리하고 최고점이 같으면 무승부다. 전멸만으로 조기 종료하는 규칙은 추가하지 않았다.

## 구조와 검증

- `battle-core/objectives.ts`: 순수 고정 tick 점령/점수/종료 함수. 기존 전투 피해와 AI를 변경하지 않는다.
- 서버: 세션 소유권 검사와 시작 권한을 유지하고, 클라이언트가 보낸 규칙/점수 값을 채택하지 않는다. 국가 시야 투영에 복제한 공개 경기 상태를 포함한다.
- 종료 tick이 홀수여도 즉시 최종 snapshot을 보내며, 결과는 재접속/hello에서도 유지된다. 게임 결과를 계정 DB에 저장하는 기능은 이번 범위 밖이다.
- UI: 거점 원·점령 현황·국가 점수·남은 전투 시간·결과·새 초대 경기 제공.
- `npm run test:objectives`: 빌드 후 실제 두 브라우저/SDK 수명 주기 검사. 테스트 전용 진입점만 짧은 시계를 사용하며, 프로덕션 서버는 그 파일을 import하지 않는다. join 옵션이나 URL로 테스트 시계로 바꿀 수 없다.

보급·관직·XP·증강 연계, 3국가9명, 전국맵, 정식 연장/천하통일/공적 순위는 아직 구현하지 않았다. 3대3 로비의 AI 보충을 이 모드로 확장하지 않았다.
