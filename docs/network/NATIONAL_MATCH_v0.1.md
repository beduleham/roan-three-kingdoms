# 현재 국가 경기 기준

현재 구현은 [Phase7 규칙 v1](PHASE7_POLICY_v1.md)을 따른다. 아래는 이전 Phase6 실험판의 이력이다. 본영 보상·수용 상한·복구·공적·증강의 현재 동작은 위 기준을 우선한다.

# Phase 6 — 3국가 경기 실험판

이 모드는 `online.html?mode=national` / `battle_national`에서 실행한다. 기존 1대1·3대3·승인된 작은 거점 시연의 규칙은 유지한다. 새 모드의 수치는 **미확정 실험값**이며 정식 밸런스가 아니다. 단일 Node 서비스와 기존 SQLite 계정 저장 구조를 사용한다.

## 플레이 흐름

1. 초대 경기를 만들고 링크로 참가한다. blue → red → green 순으로 각 국가의 1~3좌석을 배정한다. 최대 인간9명이며, 각 국가에 인간1명 이상 있는 상태에서 로비장이 시작한다. 빈 좌석은 기본 공격·거점 이동만 하는 AI가 맡는다. 시작 후 신규 입장/교체는 차단한다.
2. 각 참가자는 2부대40명으로 시작한다. 본영3개는 국가가 소유하고, 외곽3개는 2분, 중앙성은 5분에 개방한다. 본영은 점수0, 외곽은5초당1점, 중앙성은2점이다. 개방된 자기 국가 거점 주변의 실제 병력으로 점령·유지 기여를 인정한다. 전장 지도는 기존24×13타일 평면을 확장 이용하며 정식 지형은 미정이다.
3. XP는 레벨/증강, 공적은 관직/지휘 상한에 독립적으로 사용한다. 적에게 가한 실제 유효 HP 피해와 실제 점령·주둔 기여를 서버가 집계한다. 같은 tick 재처리는 거부하고 초과 피해는 보상하지 않는다. 지원·방어 기여 정규화는 아직 제외한다.
4. 기존 잠정 관직표(군후2/40→군사마2/50→교위3/60→중랑장3/75→장군4/90)에 따라 상한만 증가한다. 승진으로 병력이 생기지 않는다. 실제 추가 병력은 보급 자원을 소비해야 한다.
5. 개방된 아군 거점에 자기 유효 부대가 있고 경합/점령 중이 아닐 때 충원/추가 부대를 요청한다. 초기 보급50, 아군 거점마다5초당2를 지급한다. 충원은 최대5명·1명당2, 추가 부대는10명·비용40, 작업3초, 참가자당 작업1개다. 추가 부대 최대25명으로 원래2×20명과 합쳐 장군의4/90까지 도달할 수 있다. 죽거나 강제 후퇴 중인 부대는 충원할 수 없다.
6. 완료 시 거점 소유·경합·현장 병력·지휘 상한을 재검사한다. 충원 대상이 떠나거나, 편성 시 자기 병력이 모두 떠나거나, 거점을 빼앗기거나, 상한이 부족하면 취소하고 비용을 한 번 환불한다. 작업 중 즉시 취소 대신 완료 tick에서 조건을 판정한다. 충원은 현재 잔여 HP를 보존하고 실제 획득한 병력의 HP만 더한다. 숙련도 혼합 시스템은 이번 범위에 없다.
7. 5/10/16/22/28/34/38레벨에서 인간이 3개 후보 중 증강1개를 선택한다(총7개). 기존 Q 돌격 후 공격/속도, W 대상 전열 피해 감소의 3개 실험 효과를 각각3개 식별자로 복제한 **기능 검증용 후보군9개**다. 서로 다른 식별자 효과는 중첩될 수 있다. 정식9종 증강을 설계·검증한 것이 아니다. AI는 증강·Q/W/R·전략 후퇴·진형을 독단적으로 선택하지 않는다. 기존 R 레벨 제한도 적용한다.
8. 15분: 선두와2위 격차가 선두점수의10% 초과면 종료, 아니면18분 연장. 18분은5% 초과 기준, 아니면21분 최종 판정. 동률이면 무승부다. 10분 이후 외곽3+중앙성1을 경합 없이45초 연속 소유하면 해당 국가 천하통일로 끝낸다. 중간 경합/점령 시 연속 보유 시간이 초기화된다.
9. 종전 화면은 국가 승패와 별도로 **모든 인간**을 공적↓→국가 기여↓→playerId↑로 정렬한다. AI는 순위에서 제외한다. 인간 이탈은 승패 없는 중단이며 시작 시 인간 명단으로 중단 순위도 출력한다. 단절은 경기 전체를 멈추고 기존30초 재접속 예약을 적용한다. 종료 후 시간·명령을 동결한다.

## 데이터·권한

`national_demo.v1.json`이 비용·시간·XP곡선·기여 보상·거점 배치의 단일 실험 프로필이다. XP 테이블은40개 정수 임계값이며 특정 목표 레벨 분포를 검증한 것이 아니다. 방 생성 옵션으로 비용/XP/시간을 변경할 수 없다. 명령은 세션에 묶고, 자기 부대 소유권·형식·시야·기존 전투 검사를 적용한다. 적국의 보급/XP/공적/증강 후보/작업 내역은 보내지 않는다. 같은 국가의 성장 정보와 공개 거점·국가점수·종전 인간 순위는 투영한다.

코어는 고정 tick·정수 연산이며 네트워크·DOM·시계·무작위 API에 의존하지 않는다. 보급은 서버 큐에서 tick 단위로 실행한다. 시험 전용 서버/반복 도구는 생산 진입점에서 가져오지 않는다.

## 배포 후 확인

Render의 Manual Deploy → Deploy latest commit으로 배포한다. 세 개의 별도 브라우저/프로필에서 새 국가 경기 초대 링크로 입장하고 시작한다. 본영에서 공적/XP와 보급 증가, 2분 외곽 개방, 실제 이동·점령·국가점수, 부상 후 충원, 승진 후 추가 부대, 증강 선택을 확인한다. 15분/18분/21분 또는 천하통일 후 세 국가의 결과·전체 인간 순위가 같은지 비교한다. 종료 후 신규 명령·시간 정지가 유지되어야 한다. 이번 변경의 공개 서버 완주는 수동 배포 후 별도 인수 단계다.
