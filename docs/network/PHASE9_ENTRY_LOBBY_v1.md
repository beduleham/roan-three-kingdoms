# Phase9 — 시작·로비·조작 안내 v1

범위: Phase9 전체 첫 구현. 시작 화면, 모드 선택, 기존 혼자 연습의 실제 조작 안내, 국가·좌석 선택, 대기/준비 표시, 온라인 입장→명령→결과/다음 경기 안내를 연결한다. Phase10 운영 기능이나 새 전투/밸런스 정책을 추가하지 않는다. Phase7 사람 검증과 Google 로그인 보류는 유지한다.

## 시작 화면과 모드

빌드된 Node 서비스의 `/`는 `/play.html`로 연결한다. `/online.html`의 기존 모드별/초대 링크와 `/index.html` 로컬 전투 연습은 유지한다. Vite 개발 서버의 `/`는 기존 로컬 데모이며 시작 화면은 `/play.html`로 연다. 배포 빌드에는 index/online/play 세 entry가 모두 필요하다.

시작 화면은 국가전(3~9명, 각 국가1명 이상), 거점전(2명),1대1/3대3 전투 시연(성장·거점 결과와 별도), 혼자 조작 연습을 설명하고 실제 경로에 연결한다. 혼자 연습은 브라우저 안의 기존 LocalSession이며 온라인 좌석이나 경험치/공적을 만들지 않는다. 국가전을 인간1~2명만으로 시작시키거나 AI 국가를 새로 허용하지 않는다.

시작 화면과 조작 안내는 게스트로 사용할 수 있다. 처음부터 계정 연결을 요구하지 않고 기존 인증 계약을 그대로 따른다.

## 서버 권한 좌석 선택

`change-seat {seat}`는 자기 세션의 pre-game 좌석 변경 요청이다. 서버는 현재 세션의 연결/좌석, 지원 모드, 시작 여부, 알려진 seat ID와 점유/재접속 예약을 검사한다. 추가 필드를 가진 메시지, 다른 세션 주장, 잘못된 seat ID, 점유/예약 좌석과 시작 후 변경은 거부한다.1대1 즉시 시작 시연은 좌석 변경 대상이 아니다.

빈 좌석만 순차적으로 배정하므로 동시에 같은 좌석을 요청하면 먼저 처리된 하나만 성공한다. 로비장은 세션에 묶여 있으며 국가/좌석 변경으로 승계되지 않는다. 연결 복구도 같은 세션의 새 좌석을 복원한다. 변경 자체로 부대 위치/HP/보급/XP/공적/스킬 상태를 수정하지 않는다. 시작 시 현재 좌석을 인간 순위 명단으로 확정한다.

성공하면 로비/좌석 정보를 갱신하고 새 국가의 전체 관측 snapshot을 보낸다. 클라이언트는 이전 국가의 표시/보간/일시 연출을 비우고 새 snapshot에서 다시 그리며, 다음 델타를 새 국가 관측에 적용한다. 튜토리얼/관측 기록의 scope도 room+seat로 구분한다. 이전 좌석의 부대 명령 권한을 계속 갖지 않는다.

준비 안내는 기존 서버 시작 조건과 같은 참가국/연결 상태를 표시한다. 국가전은3국가 각각1명 이상, 팀 시연은 양국 참가자, 예약/단절 참가자가 있으면 복구를 기다린다. 시작은 로비장 권한이며 새 별도 ready 동의 규칙을 만들지 않는다. 빈자리는 기존 기본 AI가 채우고 Q/W/R·진형·전략 후퇴를 자율 사용하지 않는다.

## 튜토리얼과 회복 가능한 안내

접을 수 있는 단계별 안내는 관측된 사실만 표시하고 입력을 대신 실행하지 않는다. 혼자 연습은 실제 tick 진행, 초기 위치에서 실제 부대 이동, 자기 W의 SKILL_CAST, 자기 FORMATION_COMPLETED를 확인한다. 온라인은 입장·시작·이동·W·진형 완료·실제 결과를 현재 서버 관측으로 확인한다. 결과 없는1대1/3대3 전투 시연은 끝없는 '결과 대기' 단계를 만들지 않고 기본 조작5단계로 구분한다.

W는 로컬에서 W→전장의 아군 대상 클릭→군령 실행이 필요하고, 온라인에서는 장수와 선택 부대의 유효 조건을 따라 사용한다. 단순 클릭/시전 거부나 서버 접수 응답만으로 성공 단계를 채우지 않는다. 진행은 이 화면의 메모리이며 새 방/좌석/연습 초기화/새로고침에서 다시 관측한다. 보상·해금·실력 인증이 아니고 인간 사용성 검증을 대신하지 않는다.

로그인 세션 만료, 초대 권한, 좌석 부족과 모드 불일치는 다음 행동을 안내한다. 알 수 없는 예외/URL/토큰을 사용자 상태 문구에 그대로 출력하지 않는다. 시작 화면 도움 링크는 새 탭으로 열어 현재 경기 연결을 유지한다. 실제 나가기/예약 만료의 중단 정책은 기존대로 안내한다.

## 배포·후속 경계

Render의 최신 main을 수동 배포한 뒤 `/`의 새 시작 화면, 기존 초대 링크, 국가 변경/시야, 참가 조건, 실제 조작 가이드와 종료/기록을 확인한다. 이 버전의 공개 인수는 배포 전에는 미완료로 유지한다.

장기 이탈 정책 변경, 운영용 기록 DB/백업, 정식 매치메이킹/관리자 기능은 Phase10 이후 범위다. Phase9의 로컬/단축 fixture 브라우저 통과를 인간 플레이 편의성·15분 성장·경쟁 밸런스 또는 실제 공개 배포 통과로 부르지 않는다.
