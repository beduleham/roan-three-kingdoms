# Phase 6-2 — 같은 경기의 전국 보기와 전투 보기

적용 범위는 현재 2국가·3거점 시연 전장이다. 3국가·7지점의 새 전국 지형을 추가한 것이 아니다.

## 플레이 흐름

- 거점 경기의 전국 지도는 현재 시연 전역을 보여주고, 밝은 사각형으로 전투 화면의 범위를 표시한다.
- 지도 클릭, 거점 보기 버튼, 선택 아군으로 이동, 방향 버튼으로 전투 시점을 옮긴다. 버튼은 키보드로도 조작할 수 있다.
- 전국 보기는 전체 전역, 전투 보기는 2배 확대다. 전국 보기로 돌아갔다가 전투 보기를 누르면 이전 전투 시점 중심을 유지한다.
- 카메라 조작은 목적지/선택 부대를 변경하거나 명령을 보내지 않는다. 전장에서 아군·적을 클릭해 선택하거나 빈 땅으로 목적지를 지정한 뒤 기존 이동/공격 버튼을 사용한다.
- 확대 전장의 클릭은 카메라 역변환으로 원래 좌표에 대응한다. 거점 모드의 클릭 목적지는 0.1타일 단위로 표시한다. 지도 여백은 목적지로 사용하지 않는다.
- 시점 전환 중에도 같은 방·좌석·서버 tick·점수·결과를 유지하며 경기를 멈추거나 부대를 이동시키지 않는다. 종료 후에도 카메라로 전장을 살펴볼 수 있다. 경기에서 나가면 두 지도와 시점 정보를 초기화한다.

## 정보와 권한

두 화면은 이미 수신한 단일 국가별 BattleView만 그린다. 지도 때문에 다른 국가의 전체 상태를 요청하지 않는다. 국가 공유 시야는 두 화면에서 같은 원으로 투영하고, 시야 밖 적은 원래 마지막 위치/관측 tick 기억만 사용한다. 거점 위치·소유권·경합·진행·점수는 앞서 승인된 공개 전략 정보다. 지도는 소유권/스킬/시야 검사를 우회하는 명령 경로를 만들지 않는다.

카메라·렌더링·클릭 역변환은 클라이언트에만 추가했으며 전투 코어·서버·프로토콜은 변경하지 않았다. 기존 1대1/3대3 전투 시연의 화면 좌표 체계와 입력은 유지한다.

## 표시 설정과 한계

`apps/client/src/map-view.json`은 전역 표시 크기24×13타일, 전투 확대2배, 화면 여백을 관리하는 표현용 설정이다. 서버의 이동 제한이나 전투 수치가 아니다. 실제 국가 경기 지형의 크기·배치·지형 차폐·이동 경로는 후속 기획/개발 사항이다.

현재는 평면 지도, 부대 아이콘, 공개 거점과 시야 표시를 사용한다. 별도 지형 아트·전략 명령·거점 보급·성장 통합은 포함하지 않는다. 카메라 위치는 재접속 페이지 새로고침 시 기본값으로 돌아갈 수 있으며 경기 상태는 서버에서 복구한다.

## 검증

- `npm run test:maps`: 생산 빌드와 실제 두 브라우저로 카메라/방/상태 유지, 확대 클릭·이동·점령, 시야/마지막 관측을 확인한다. 테스트 서버는 정상 거점 경기 설정을 사용한다.
- 카메라 단위 검사는 여러 화면 비율과 확대율의 좌표 왕복·모서리 제한·여백 무시·잘못된 입력을 확인한다.
- 거점 경기 완주/결과 검사와 기존 온라인 회귀 검사를 함께 실행한다.
- 공개 Render 적용과 외부 지도 인수 검사는 수동 배포 후 진행한다.
