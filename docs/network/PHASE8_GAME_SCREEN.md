# Phase 8 — 실제 게임 화면 완성

2026-11-01 사용자 지시: Phase7의 실제 인간 위치/역할 교대 경기·성장 분포·증강 효용·지원/방어 평가는 보류하고 Phase8로 진행한다. 이는 밸런스 인수 통과가 아니다. Phase7 v1 규칙/실험 표시는 유지하고 화면 작업을 진행한다.

## 첫 묶음: 온라인 HUD와 기존 아트 연결

- 중국풍의 인장·먹색/비단색 패널·황동 테두리로 접속/로비, 전장, 하단 군령, 우측 전국 지도·성장/보급을 배치한다. 인장/장수 표기는 한글로 두어 한자 글리프가 없는 환경의 깨진 글자를 피한다.
- 서버 검증·입력 ID·카메라 세계좌표·국가 시야/마지막 관측 계약을 유지한다. 원본 관측 상태/긴 전투 로그는 접을 수 있고, 명령 접수/거부는 조작 패널에서 계속 보인다.
- 로컬 Phaser 데모에서 쓰던 기존 보/창/궁/기/장수9개 SVG sprite atlas를 온라인 Canvas에도 연결한다. 프레임 사각형·발 기준점은 기존 motion-atlas를 읽고 이미지들은 한 번만 로드한다.
- 전국 보기의 한 부대 한 표식과 확대 전투 보기의 최대4명 축약 편대는 표시용이다. 실제 병력은 기존 서버 HUD/병력 막대가 나타낸다. 표시 병사에 별도 AI/피격 판정은 없다.
- 방향·이동은 관측 위치/방향, 공격은 받은 ATTACK_HIT 사건으로 재생한다. 패주/붕괴 시 기존 상태 피드백을 사용하고 공격 불가 상태의 공격 프레임은 차단한다. 본대가 있고 ACTIVE인 장수만 본대 표시를 붙이며 부상·재배속 중인 장수의 위치를 만들어 내지 않는다.
- 알려진 적에만 기존 서버 관측을 사용한다. 가려진 적·기억 위치에 현재 병종 애니메이션을 재생하지 않는다. 새 접속 때 모션 캐시를 초기화한다.
- 이미지 실패는 화면 대체 표식으로 처리하고 명령 입력을 막지 않는다. 선택 범위에는 보이는 몸체의 발 위 영역도 포함한다. 캔버스 프레임율로 공격/성장/보급을 계산하지 않는다.
- 데스크톱에서 전장과 보급 패널을 나란히, 좁은 화면에서는 세로로 배치한다.390px에서 가로 넘침과 실제 명령 접수를 검사한다. 모바일 게임 조작감이나 저사양 성능 인증은 아니다.

검증 결과(2026-11-01): 자동 테스트 **458개/38파일**, TypeScript·production build·Prettier·diff 검사 통과. Chromium **31개**(국가4/온라인15/지도4/거점4/네트워크4)가 통과했고, 최종 글꼴 수정 후 HUD 화면 검사1개를 추가 재실행했다. 재실행을 독립 테스트 수에 중복 합산하지 않는다. 기존 화면 고정 픽셀을 클릭하던1대1 검사도 실제 canvas/CSS 배율로 환산해 같은 세계좌표를 계속 검증하도록 수정했다.

## 이번에 포함하지 않은 범위

온라인 지도 투영은 기존 평면 좌표를 유지한다. 로컬 데모의 쿼터뷰가 온라인에도 완성됐다고 표기하지 않는다. 완전한 쿼터뷰에는 전장·미니맵의 투영/역변환, 시야 범위의 투영과 클릭/병력 겹침 검사가 추가로 필요하다.

피격/패주/부상 전용 신규 sprite clip, Q/W/R 고유 시각효과·효과음, 사용자 음량/음소거, 리소스 예산/프레임 성능 측정은 후속 작업이다. 현재의 기존 이동/공격 클립·상태 텍스트/투명도 연결과 구분한다. 새 지도·밸런스 수치·추가 장수·지원 가중치·Google 로그인·Phase9 작업은 없다.

- 실제 Chromium 국가 경기4개(기존3개 및 HUD desktop/narrow 검사), 기존 온라인15·지도4·거점4·네트워크4 회귀. 내 경기 기록 다운로드도 계속 검사한다.
