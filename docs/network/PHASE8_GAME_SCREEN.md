# Phase 8 — 실제 게임 화면 완성 v1

상태: 8-1~8-6 **개발·로컬 검증 완료**, 새 Render 공개 화면의 배포/인수 대기. Phase9는 미착수다. 2026-11-01 사용자 요청으로 Phase7 실제 인간 위치/역할 교대·성장 분포·증강 효용·지원/방어 평가는 보류한다. 미검증을 정식 밸런스 통과로 바꾸지 않는다.

## 구현한 화면 계약

- 전장·하단 군령·우측 전국 지도와 성장/보급을 중국풍 인장·먹색/황동 패널로 배치한다. 실제 입력 ID, 초대·로비·재접속·결과·JSON 기록 저장은 유지한다. 긴 원본 관측/진단은 접을 수 있다.
- 국가/거점 경기 전장은2:1 쿼터뷰, 미니맵은 평면이다. 같은 세계 좌표/viewport를 사용하고 정·역변환, 다이아몬드 여백 클릭 거부, 시야/점령 원의 타원 투영, x+y 깊이 순서로 그린다. 기존1대1/3대3 전투 비교 시연은 평면 표시를 유지한다. 지형의 높이·차폐·통행 규칙을 새로 만들지 않는다.
- 본인 부대·선택 대상 이름을 우선 표시하고 모든 부대 이름 옵션을 제공한다. 국가 시야 밖 적의 현재 몸체/애니메이션을 그리지 않고 기억 위치/시각은 기존 계약을 따른다. 전국 보기 한 부대 한 표식·확대 보기 최대4명 축약 편대는 표시용이며 실제 병력/HP 판정이 아니다.

## 애니메이션·스킬 연출

기존 보/창/궁/기/장수9개 atlas의 방향/이동/공격 프레임을 재사용한다. 대기 호흡, 피격 반동, 붕괴 흔들림, 패주 보폭, 관측된 장수 부상의 회전/페이드는 procedural 표시 clip이다. 신규 수작업 bitmap frame 세트를 제작했다고 주장하지 않는다. ACTIVE 장수만 본대 표시를 붙이고 부상 연출은 알려진 본대 위치에서 짧게 사라지는 표시로 구분한다. 권위 장수/부대 위치를 복제하거나 이동시키지 않는다.

Q는 실제 CHARGE_IMPACT, W/R은 성공한 SKILL_CAST에 각각 다른 색의 링/표식을 사용한다. 일반 타격, 패주/장수 부상 전이, 경기 종료도 관측된 사건/상태만 소비한다. 시전 거부, 미래/오래된 사건, 현재 가려진 actor를 임의 성공 연출로 바꾸지 않는다. 전체 스냅샷은 baseline이고 과거 연출을 재생하지 않으며 검증 델타의 중복 사건을 제거한다. 방 변경은 표시 캐시를 초기화한다.

연출은 최대48개·중복 키2048개·기본18tick 수명으로 제한하고 현재 관측에서 사라진 개체의 연출은 제거한다. 종료 시 일시 효과를 정리한다. 실제 스킬 사거리/피해/유효 대상 숫자와 장식 링의 픽셀 반경은 별개다.

## 효과음·접근성

처음에는 음소거다. **효과음 켜기**를 누른 사용자 동작에서만 AudioContext를 생성/재개한다. Q/W/R·타격·패주·장수 부상·종료를 구분하는 합성 cue, 음량 slider, 음소거가 있다. 새 녹음 리소스나 외부 음원 요청은 없다.

같은 관측 사건을 중복 재생하지 않고 재동기화 스냅샷은 무음이다. 최대6voice·80ms 간격으로 과도한 소리 겹침을 막는다. 음량0·음소거·숨김 탭에서는 재생하지 않고 탭 숨김/경기 이탈 시 현재 소리를 멈춘다. 브라우저 오디오 시작 실패는 안내하고 경기 입력은 유지한다. 단축 시계의 시험 결과나 합성 oscillator 시작 검사는 실제 스피커 음질에 대한 인간 평가가 아니다.

**연출 줄이기**와 OS `prefers-reduced-motion`은 걷기/공격 프레임과 반동/확장 효과의 움직임을 줄인다. 필요한 현재 부대 위치와 실제 상태는 계속 표시한다. 좁은390px 배치·키보드 가능한 HTML controls를 검증했으나 터치 게임 조작감이나 모든 보조공학 인증은 아니다.

## 리소스와 프레임 예산

초기에는 창/궁 이동·장수3개 atlas를 요청하고 다른 병종/공격 atlas는 필요할 때 한 번만 로드한다. 대기 중인 공격 atlas는 기존 이동 프레임으로 대체하고 실패한 이미지는 fallback 표식으로 표시한다. 방을 바꿔도 같은 페이지의 아트 캐시는 재사용하며 입력을 자원 로딩에 묶지 않는다.

표현 목표는 약30fps(33ms 최소 간격)다. 서버10Hz/동기화5Hz·스킬/보급 시간은 그대로다. 미니맵은 tick/카메라가 바뀔 때만 다시 그린다. 숨긴 페이지는 표현을 생략하고 성능 집계는 숨김 시간을 프레임 간격에 섞지 않는다. paint/간격 표본은180개로 제한한다.

로컬 Chromium3클라이언트 시험에서29.0~29.4fps, Canvas를 그리는 JS 처리 p95 1.0~1.1ms를 관측했다. 이는 짧은 가속 시험의 특정 실행 환경 값이며 GPU 전체 paint·장기 메모리·저사양 기기·실제 휴대전화의 성능 보장이 아니다. [원시 표본](../demo/phase8-render-sample.json), [검증 보고서](../demo/phase8-completion-validation.md).

## 배포와 범위

Render에서 Manual Deploy → Deploy latest commit 후 새 국가 경기에서 쿼터뷰/클릭/시야, 효과음 기본 꺼짐과 수동 켜기/끄기, 좁은 화면, 종료/기록 저장을 확인한다. 진행 중 방을 마이그레이션하지 않는다.

이번 완료는 화면·연출 v1의 개발/로컬 검사 범위다. Phase7 사람 밸런스, 정식 전국 지형/차폐, 새 장수 콘텐츠/수작업 고급 sprite 제작, 모든 장치 성능 인증, Google 로그인·Phase9 개발을 완료했다고 표시하지 않는다.
