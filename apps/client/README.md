# 로컬 전투 데모 — demo-order-v0.1

Phaser 도형 렌더링 + 기존 battle-core의 첫 로컬 조작 데모입니다. 실제 서버 권위/멀티플레이가 아닙니다.
Phase 3의 운영 콘텐츠·9종 확장 및 Phase 4 전체는 미완료입니다. 아트·네트워크·성장·거점 승리 판정은 없습니다.

## 실행

Node.js 22.12 이상 (이 환경에서는 24.19로 검증), 저장소 루트에서:

```sh
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소(기본 포트 5173)를 브라우저에서 엽니다. 별도 서버나 API 키는 필요하지 않습니다.
프로덕션 정적 파일은 npm run build 실행 후 apps/client/dist에 생성됩니다.

## 편성과 조작

- 각 진영 2부대, 부대당 20명. 양쪽의 보병·창병·궁병·기병을 선택한 뒤 **편성 적용 · 초기화**를 누릅니다.
- 시작 레벨 16은 R 및 증강 선택 검증용 데모 설정입니다. XP·레벨 성장 구현이 아닙니다.
- 처음과 초기화 직후는 일시정지입니다. **시작 / 계속** 또는 Space로 시작/정지합니다.
- 아군 클릭 또는 1/2로 선택, Shift와 함께 선택하면 복수 선택입니다. 적을 아군처럼 선택할 수 없습니다.
- 빈 곳 우클릭은 MOVE, 적 우클릭은 ATTACK. 공격 이동(A)·후퇴(T)는 버튼/키를 누른 뒤 목적지를 우클릭합니다.
- 태세·진형을 고른 뒤 적용 버튼을 누릅니다. 사거리·추격 한도·전환시간·명령 가능 여부는 코어가 판단합니다.
- **Q**: 실행 부대를 하나 선택 → Q → 적 클릭 → **시전 확인/Enter**. 버튼만으로 충돌하지 않습니다.
- **W/R**: 스킬 버튼 → 적용할 아군 부대를 클릭해 대상 목록 지정/해제 → **시전 확인/Enter**.
  대상 수·병종·레벨·지휘 반경·쿨다운을 코어가 검증하고 거부 사유를 HUD에 표시합니다.
- 선택 번호키로 부대를 바꾸거나 Esc를 누르면 미확정 스킬 지정을 취소합니다. 스킬 지정 중 우클릭은 취소만 하며 이동은 다시 우클릭해야 합니다.
- 장수 재출전 뒤에는 자기 부대를 하나 선택하고 재배속 버튼으로 실제 이동시킵니다. 부상·쿨다운·재출전 tick은 HUD에서 확인합니다.
- 방향키로 화면을 이동합니다. 지도 격자는 시각적 안내이며 코어의 맵 경계나 장애물이 아닙니다.
- 90초 이후에도 계속 실행할 수 있습니다. 전멸 시에도 별도의 승리 판정으로 종료하지 않습니다.

## 증강·AI·로그

기본 증강은 꺼져 있습니다. **실험용 증강** 체크 후 초기화한 경우에만 experimental-v0.1 정의를 신뢰된 시나리오에 주입합니다.
실제 후보 3개만 표시하며 미선택은 보류 상태입니다. 한 번 선택 후 후보가 부족하면 남은 2개 기회를 보존하고 후보 부족을 표시합니다.
자동 선택·가짜 후보·공적/XP 환급은 없습니다. 효과와 수치는 운영 밸런스 미검증입니다.

상대는 코어의 실행 AI(기본 교전·추격·복귀)입니다. 별도 명령 생성 AI가 없으므로 Q/W/R·진형·전략적 후퇴·증강을 자동 선택하지 않습니다.
초기 적 태세는 balanced, 인간 태세는 defensive입니다. 이는 데모 시나리오 편성이며 규칙 변경이 아닙니다.

**전체 로그 JSON**에는 최초 상태(설정·편성·실험 정의 포함), 매 tick 명령, 최종 상태/이벤트 해시가 들어갑니다.
코어 replay(initial, frames)로 재현할 수 있습니다. 화면에는 주요 사건만 표시하지만 모든 코어 사건이 이벤트 해시에 포함됩니다.
로컬 어댑터가 human ID, seq, requestedTick을 지정합니다. 브라우저 프로세스를 신뢰하는 데모 경계이며 서버 인증을 구현한 것은 아닙니다.

## 검증 명령

루트에서 순차 실행:

```sh
npm run typecheck
npm run test
npm run build
npm run sim:smoke
npm run format:check
```

브라우저 검증(Playwright):

```sh
npx playwright install chromium
npm run test:browser
```

이미 설치한 Chromium을 사용하려면 DEMO_CHROMIUM_PATH 환경 변수에 실행 파일 경로를 지정합니다.
예: DEMO_CHROMIUM_PATH=/usr/bin/chromium npm run test:browser.
브라우저 테스트는 실제 입력과 headless 해시 비교를 포함합니다. 실제 시계로 90초 실행하는 사례만 140초 제한이며 나머지는 기본 제한입니다.
설치나 실행이 차단된 환경에서는 브라우저 미검증으로 보고해야 합니다. 단위 테스트는 브라우저 렌더링 검증을 대체하지 않습니다.

이번 실행의 검사 결과와 화면은 [검증 기록](reports/VALIDATION.md)에 있습니다.
