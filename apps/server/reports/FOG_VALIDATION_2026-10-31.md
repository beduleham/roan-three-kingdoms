# 국가 공유 시야 적용 후 검증 · 2026-10-31

사용자가 선택한 국가 공유 시야·마지막 위치/관측 tick 기억·10타일 실험 반경을 적용했다. 세부 계약은 [시야 시연 문서](../../../docs/network/VISIBILITY_v0.1.md)에 기록했다.

## 통과 결과

- 타입 검사·빌드·포맷 검사.
- 단위 테스트 326개. 기본 코어 회귀와 시야/전송 경계 검사 포함.
- 온라인 브라우저 11개. 시야 밖 적의 대상 목록/상태 제거, 기억 고정, 변조한 직접 지정 명령 거부, 새로고침 이후 기억 유지, 재관측을 실제 두 페이지에서 검사했다.
- 실제 서버 두 SDK 접속에서 관측 델타 해시와 양측에 동시에 보이는 부대 상태의 일치를 검사했다. 전체 코어 상태나 부대 명령 필드가 스냅샷에 포함되지 않는 것도 확인했다.

## 900tick 실행

`npm run test:online:soak` 기본 설정을 사용했다.

| 항목                          | 결과                                      |
| ----------------------------- | ----------------------------------------- |
| 실제 SDK 연결                 | 6개, 국가별 3개                           |
| 도달 tick / 실측 경과         | 900 / 90.37초                             |
| 공통 tick 표본                | 450개, 각 국가 안에서 해시 전부 일치      |
| 의도적 델타 누락              | tick 20, 전체 관측 상태 재수신 1회로 복구 |
| 강제 연결 종료                | blue-3에서 1회, 같은 좌석 자동 복귀       |
| 입력 큐 접수                  | 좌석별 45/45/45/45/44/45회                |
| NOT_OWNER / INVALID_FORMAT    | 각각 45회 거부                            |
| 한 연결의 평균 델타 JSON 크기 | 3,438byte                                 |
| blue 최종 관측 해시           | `c6d73b111df5a228`                        |
| red 최종 관측 해시            | `2291b2cccaa32cc4`                        |

반복 입력 접수는 전투 조건에 따른 최종 실행 성공과 구분한다. JSON 크기는 실제 전송 프레임 크기나 운영 성능 한계 측정이 아니다. 이번 검사부터 해시 범위는 전체 경기 대신 국가별 관측 상태이며, 안개 적용 전의 장시간 검사 기록과 직접 비교하지 않는다.
