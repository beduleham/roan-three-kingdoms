# 3대3 온라인 시연 장시간 검증 · 2026-10-31

## 실행과 범위

`npm run test:online:soak`으로 로컬 Node 서버 하나와 Colyseus SDK 연결 6개를 실제 WebSocket으로 연결했다. 서버의 100ms tick과 200ms 델타 방송을 사용하고, 단축용 환경 변수는 지정하지 않았다.

| 관측 항목                    | 실행 결과                                |
| ---------------------------- | ---------------------------------------- |
| 서버 전투 진행               | 900tick                                  |
| 시작 후 실측 경과            | 90.36초                                  |
| 접속자                       | blue/red 각 3좌석, 총 6개                |
| 전원이 공통 관측한 tick 표본 | 450개, 해시 전부 일치                    |
| 의도적으로 누락한 델타       | tick 20, blue-2 연결                     |
| 누락 후 전체 상태 재동기화   | blue-2에서 1회, 이후 일치 유지           |
| 강제 연결 종료               | blue-3에서 1회, 같은 세션·좌석 자동 복귀 |
| 서버 입력 큐 접수 응답       | 좌석별 45/45/45/45/44/45회               |
| 타인 명령 거부               | NOT_OWNER 45회                           |
| 잘못된 형식 거부             | INVALID_FORMAT 45회                      |
| 델타 메시지 평균 JSON 크기   | 한 연결에서 4,119byte                    |
| 마지막 공통 상태 해시        | `0c735a6a7a921ac8`                       |

입력 큐 접수는 전술 명령의 최종 실행 성공과 구분한다. 코어는 강제 상태·전멸·사거리 등 전투 조건을 다음 tick에서 별도로 판단한다. 평균 크기는 SDK에서 복호화된 델타 메시지의 JSON 직렬화 크기이며 실제 전송 프레임 크기나 서비스 수용량 측정이 아니다.

## 함께 통과한 검사

- 타입 검사, 빌드, 포맷 검사.
- 단위 테스트 319개. 누락·변조·과거 델타 거부와 전체 스냅샷 이후 복구 포함.
- 온라인 브라우저 테스트 10개. 1대1/3대3 동기화·재접속·로비 권한·초대 키·참가자 제거 포함.

## 아직 확인하지 않은 범위

실제 인터넷의 지연·손실 분포, 다중 서버 운영 한계, 브라우저 간 호환성, 끊긴 동안의 사건 로그 재전송과 완전한 온라인 리플레이는 이 결과에 포함하지 않는다. 계정 인증·시야 및 정보 가림·국가 점수와 정식 승리 규칙·게임 밸런스도 별도 범위다.
